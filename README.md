# Euler en el espacio

## Simulador numérico de lanzamiento vertical de un cohete

**Proyecto académico – Métodos Numéricos**  
**Universidad Mayor de San Andrés (UMSA)**  
**Carrera de Informática**

## Descripción

Este proyecto consiste en una aplicación web interactiva que simula el movimiento vertical de un cohete experimental mediante ecuaciones diferenciales ordinarias.

Permite modificar los parámetros físicos del lanzamiento y comparar los resultados obtenidos mediante diferentes métodos numéricos.

## Métodos implementados

- Método de Euler.
- Método de Heun.
- Método de Runge-Kutta de cuarto orden (RK4).
- Solución analítica exacta.

## Funcionalidades

- Configuración de parámetros físicos.
- Simulación del lanzamiento vertical.
- Tabla de iteraciones.
- Gráficas de velocidad y altura.
- Comparación de errores y precisión.
- Preguntas de reflexión y conclusiones.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js

## Objetivo académico

Analizar el comportamiento de los métodos numéricos aplicados a un problema de lanzamiento vertical, comparando sus resultados con la solución analítica y evaluando la influencia del tamaño del paso de integración.
